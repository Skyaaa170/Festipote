Première fois ? Créer le code organisateur

Le code se crée une seule fois, dans Supabase, pour que personne d'autre ne puisse le faire à ta place. Dans SQL Editor, lance :

select org_init('ton code secret');

Relancer cette ligne remplace le code, si tu l'as oublié.
